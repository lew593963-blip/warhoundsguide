# Page Plan — Squad & Classes Guide

- Page ID: `squad-guide`
- Priority: P0
- Merged cluster: `warhounds best classes`
- Search intent: help players combine the five confirmed class roles without publishing an unsupported tier list.
- Required sections: direct answer, five-class roster, role coverage, three adaptable squad patterns, veterans vs recruits, equipment fit, FAQ.
- Evidence boundary: name only officially documented classes and roster systems; explain that role descriptions beyond official wording are planning heuristics.
- Internal links: beginner guide, weapons guide, base upgrades.
- Exclusions: exact class rankings, unpublished skill-tree details, invented squad-size limits, character-specific statistics.
- Success condition: the reader can identify coverage gaps and choose a squad appropriate to a mission objective.
